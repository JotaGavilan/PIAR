Què és Màquina Ensenyable?

Una aplicació per a entrenar els teus propis models d'IA en el mòbil, sense programar i sense cap compte. Tot es processa en el teu dispositiu: les imatges i els moviments no s'envien a cap servidor.

Com es fa servir

  1. Dades: tria el tipus de model (imatge, postura o mans) i crea les classes. Pots partir d'un conjunt d'exemple.
  2. Dades: afig mostres a cada classe amb la càmera (mantín premut el botó) o pujant imatges.
  3. Entrenar: ajusta els paràmetres si vols (els valors per defecte funcionen bé) i prem «Entrenar model».
  4. Provar: comprova el model amb la càmera o una imatge.
  5. Exportar o Guardar: descarrega el model o guarda tot el projecte en un fitxer .mia.json.
  6. Teachable Microbit: a la pestanya Guardar, prem «🚀 Obrir a Teachable Microbit» per a usar el model amb la micro:bit; s'obri ja carregat.

Tipus de model

  • 🖼 Imatge: reconeix objectes, gestos o expressions. Mínim 3 mostres per classe; amb 20–50 de variades va molt millor.
  • 🕺 Postura: reconeix la posició del cos amb la càmera frontal. Col·loca't de manera que es veja el cos sencer.
  • 🤚 Mans: reconeix gestos de la mà amb la càmera frontal. Només es guarda la mostra si es detecta una mà.

Consells

  • Varia la distància, la llum i el fons mentre captures mostres.
  • Canviar de tipus de model esborra les classes, les mostres i el model entrenat (l'aplicació t'ho preguntarà).

Internet i mode avió

  • Cal Internet només per a descarregar els models base (MobileNet, PoseNet, mans): la primera vegada que uses cada tipus de model. Després queden guardats en el dispositiu, i amb «📥 Ús sense Internet» de la portada els descarregues tots d'una vegada.
  • Quan el model base està descarregat, pots llevar el Wi-Fi i les dades mòbils: la càmera es processa en el dispositiu i no s'envia res a cap servidor.
  • Si canvies a un tipus de model que encara no s'ha descarregat, cal Internet. L'aplicació t'ho avisa; si falla la descàrrega, et dirà que revises la connexió.
  • Esta aplicació no necessita Bluetooth, així que pots usar el mode avió una vegada descarregats els models.
  • Sense Internet, l'aplicació només s'obri si ja l'has instal·lat o usat abans amb connexió, i només funcionen els models ja descarregats. Des de la portada, «📥 Ús sense Internet» els descarrega tots.

Limitacions

  • Esta aplicació no envia dades a la micro:bit. Per a això, consulta l'aplicació Teachable Microbit.
