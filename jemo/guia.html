1

Què és i com funciona

JEmo mira amb la càmera la cara, les mans, el cap i, si es veu, el cos d'una persona i envia a la micro:bit, per Bluetooth, quina emoció té la cara (alegria, tristesa, enuig, sorpresa, por, fàstic o neutra) i quin gest fas (saludar, puny, polze amunt, dir que sí o que no amb el cap, braços amunt…). Són missatges de text curts, com E1:87 o G2:90, que tu decideixes què fan a la micro:bit.

Què necessites

  • Un mòbil Android amb Chrome (o un ordinador amb Chrome o Edge) amb càmera. En iPhone/iPad el Bluetooth web no funciona, però pots veure la lectura a la pantalla.
  • Una micro:bit amb el programa d'esta guia (es fa en 10 minuts). Sense micro:bit també val: veuràs les lectures i els missatges a la pantalla.
✅ Privacitat. Tot el càlcul es fa dins del teu dispositiu. No s'envia cap imatge ni cap vídeo a Internet ni es guarda res: només el text curt cap a la micro:bit.
⚠️ Què fa i què no fa. JEmo detecta l'expressió de la cara (el gest que fa), no el que sent la persona. Pot equivocar-se, sobretot amb llum dolenta, mascareta o si no mires a la càmera. Serveix per a jugar i aprendre, no per a avaluar ningú. Llig una sola persona.
2

Crea un projecte en MakeCode

Obri makecode.microbit.org en el navegador (en un ordinador o en un Android amb Chrome). Prem New Project i posa-li un nom, per exemple jemo.

ℹ️ Idioma. MakeCode es pot posar en valencià, castellà, etc. (⚙ → Language). Esta guia dibuixa els blocs en anglés, que és l'idioma per defecte; en un altre idioma els colors i l'ordre dels blocs són els mateixos.
3

Activa el Bluetooth: afig l'extensió

Per defecte, MakeCode no inclou els blocs de Bluetooth. Cal afegir l'extensió:

  1. Al final de la barra de blocs, prem Extensions (o ⚙ → Extensions).
  2. Escriu bluetooth en el cercador i prem la targeta bluetooth.
  3. Torna al projecte: ja tens la categoria Bluetooth (color blau).
⚠️ Radio i Bluetooth no poden anar junts. Si el projecte ja usava blocs de ràdio, MakeCode t'avisarà que cal llevar-los: la micro:bit no pot usar les dos coses alhora.
4

Fes el projecte «sense vinculació»

Este és el pas que més falla. Per defecte, una micro:bit amb Bluetooth exigeix vincular-se abans de connectar (el clàssic dibuix amb el patró de LEDs). Des d'una pàgina web això no funciona bé, així que cal fer un projecte sense vinculació:

  1. Prem l'engranatge ⚙ (dalt a la dreta) → Project Settings.
  2. Marca No Pairing Required: Anyone can connect via Bluetooth.
  3. Tanca el diàleg. El canvi es guarda dins del projecte, i s'aplica en descarregar-lo.
⚠️ Vinculació antiga. Si el mòbil ja s'havia vinculat abans a esta micro:bit, ves a Configuració → Bluetooth del mòbil i prem Oblida en el dispositiu «BBC micro:bit». Si no, pot continuar demanant la vinculació antiga.
5

El programa de la micro:bit

La micro:bit rep una línia de text cada vegada que JEmo envia alguna cosa. El programa fa tres coses: separa el codi (el text abans de «:», p. ex. E1 o G10) de la força (el número després de «:»), tria què fer segons el codi i, si vols, usa la força (ací, per a la lluentor dels LEDs).

Per a no haver de muntar tots els blocs a mà, copia el codi, ves a la pestanya JavaScript de MakeCode, esborra el que hi ha, apega'l i torna a Blocks:

let linia = ""
let parts: string[] = []
let codi = ""
let forca = 0
bluetooth.startUartService()
bluetooth.onBluetoothConnected(function () {
    basic.showIcon(IconNames.Yes)
    basic.pause(500)
    basic.clearScreen()
})
bluetooth.onBluetoothDisconnected(function () {
    basic.showIcon(IconNames.No)
    basic.pause(500)
    basic.clearScreen()
})
bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    linia = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))
    parts = linia.split(":")
    codi = parts[0]
    forca = 100
    if (parts.length > 1) {
        forca = parseInt(parts[1])
    }
    if (codi == "E0") {
        basic.showIcon(IconNames.Meh)
    } else if (codi == "E1") {
        basic.showIcon(IconNames.Happy)
    } else if (codi == "E2") {
        basic.showIcon(IconNames.Sad)
    } else if (codi == "E3") {
        basic.showIcon(IconNames.Angry)
    } else if (codi == "E4") {
        basic.showIcon(IconNames.Surprised)
    } else if (codi == "E5") {
        basic.showIcon(IconNames.Confused)
    } else if (codi == "E6") {
        basic.showIcon(IconNames.Silly)
    } else if (codi == "E9") {
        basic.clearScreen()
    } else if (codi == "G1") {
        basic.showIcon(IconNames.Heart)
    } else if (codi == "G2") {
        basic.showIcon(IconNames.Butterfly)
    } else if (codi == "G3") {
        basic.showIcon(IconNames.No)
    } else if (codi == "G4") {
        basic.showIcon(IconNames.Ghost)
    } else if (codi == "G5") {
        basic.showIcon(IconNames.Asleep)
    } else if (codi == "G6") {
        basic.showIcon(IconNames.Tortoise)
    } else if (codi == "G7") {
        basic.showIcon(IconNames.Target)
    } else if (codi == "G8") {
        basic.showIcon(IconNames.Sword)
    } else if (codi == "G9") {
        basic.showIcon(IconNames.Fabulous)
    } else if (codi == "G10") {
        basic.showIcon(IconNames.Diamond)
    } else if (codi == "G11") {
        basic.showIcon(IconNames.Yes)
    } else if (codi == "G12") {
        basic.showIcon(IconNames.No)
    }
    led.setBrightness(Math.map(forca, 0, 100, 40, 255))
})

6

Descarrega el programa a la micro:bit

Quan els blocs estiguen llestos:

  1. Posa nom al projecte i prem ⬇ Download. Es baixa un fitxer .hex.
  2. Amb ordinador: connecta la micro:bit amb el cable USB; apareix com una unitat MICROBIT. Arrossega-hi el fitxer .hex. El LED groc de darrere parpelleja i, en acabar, la micro:bit es reinicia sola.
  3. Amb un Android: necessites un cable USB-OTG. Connecta la micro:bit i copia el .hex a la unitat MICROBIT amb l'app de fitxers (o, si Chrome ho ofereix, connecta-la amb «Connect device» des de MakeCode).
  4. Desconnecta el cable USB i alimenta la micro:bit amb la seua bateria (portapiles de 2 pilotes AAA) o deixa-la en un carregador/bateria USB.
ℹ️ Recorda. Cal tornar a descarregar el programa cada vegada que canvies els blocs o la configuració del projecte (per exemple, «No Pairing Required»).
7

Connecta la micro:bit amb JEmo

Amb la micro:bit encesa i el programa descarregat:

  1. Obri JEmo en Chrome (Android) i permet l'accés a la càmera quan el navegador ho demane.
  2. Comprova que el Bluetooth del mòbil està activat (i, en Android 11 o anterior, també la ubicació; en Android 12 o posterior, el permís de dispositius propers).
  3. Prem 🔵 Connectar Bluetooth.
  4. Chrome mostra la llista de dispositius. Tria BBC micro:bit [tugiv] i prem Vincula (Pair).
  5. Si tot va bé, el botó es posa verd i diu ✓ Bluetooth connectat, apareix el nom del dispositiu i la micro:bit mostra una ✔ un instant.
⚠️ iPhone i iPad. Safari i Chrome d'iOS no permeten Web Bluetooth: no pots connectar la micro:bit des d'un iPhone/iPad. Usa un Android o un ordinador amb Chrome o Edge. Pots comprovar el teu mòbil amb el Test del mòbil.
8

Activa la càmera

  1. Prem 📷 Activar la càmera i accepta el permís de Chrome.
  2. Espera uns segons: es carreguen els models d'IA (només la primera vegada).
  3. Col·loca el mòbil a l'altura de la cara, amb llum al davant i la teua cara dins de la imatge. Amb la càmera frontal del mòbil deixa la vista en «Cerca» (és la que ve per defecte): veu la cara i les mans. Si el mòbil està lluny, amb suport, pots triar «Cos sencer» (mira el pas 10).
  4. Mira les targetes: Emoció a l'esquerra i Gest a la dreta, cada una amb el missatge que s'enviarà (p. ex. E1:84). Sota, les 7 barres mostren com de segura està la xarxa de cada emoció.
  5. El botó 🔄 canvia entre la càmera frontal i la de darrere; ⏹ l'apaga.
⚠️ Permís de la càmera. Si el neges, toca el cadenat de l'adreça → Permisos → Càmera. Si una altra app usa la càmera, tanca-la.
ℹ️ Cal ser una persona. Si hi ha diverses cares, llig la més clara. Si no es veu cap cara, envia E9 una vegada i esperarà a què torne.

Les 7 emocions

CodiEmocióCom la veu el model
E0😐 NeutraCara relaxada, sense gest marcat.
E1😀 AlegriaSomriure, comissures amunt (la més fiable).
E2😢 TristesaComissures avall, celles inclinades.
E3😠 EnuigCelles baixes i juntes, llavis tensos.
E4😮 SorpresaCelles amunt i boca oberta (molt fiable).
E5😨 PorCelles amunt i juntes, ulls molt oberts.
E6🤢 FàsticNas arrugat, llavi superior alçat (la més difícil).
E9🫥 Sense caraNo es veu cap cara (s'envia una sola vegada).

Es tria a ⚙️ Configurar → Què llig → Model de la cara.

ℹ️ Per què dubta? Una IA no «veu» emocions: compara la teua cara amb les cares amb què es va entrenar. Si fas un gest exagerat l'encerta; si ets subtil, dubta. Això és el que mostren les barres.

Els gestos: mans, cap i cos

Amb la càmera frontal del mòbil només es veu la cara i, com a molt, una mica del pit. Per això JEmo té dues vistes; tria-les a Configuració → Com et col·loques:

VistaQuan usar-laQuè llig
Cerca (per defecte)Càmera frontal del mòbil, a un braç de distància.Les mans, els moviments del cap, la mà a la cara o sobre el cap i, si es veuen, les espatlles.
Cos sencerMòbil o portàtil lluny (1–2 m), amb suport, i tu dret o assegut en un pla ample.Braços amunt, braços creuats, saludar, mans a la cara, cap inclinat i esquena caiguda (model de postura PoseNet).

Vista «Cerca»

Tres models treballen junts: la malla de la cara (cap i cara), MediaPipe Hands (21 punts de cada mà) i, si ho actives, PoseNet només per a les espatlles. JEmo calcula un gest cada vegada.

CodiGestCom es detecta
G0🧍 Cap gestRes de especial.
G2👋 SaludantMà oberta movent-se a un costat i a l'altre.
G4🤦 Mà a la cara o sobre el capMà oberta (o a mitges) tocant la cara o damunt del cap. Si la mà és molt més gran que la cara, es veu que està davant de la càmera i compta com a mà oberta.
G5🤔 Cap inclinatLa línia dels ulls s'inclina (15° per defecte).
G6🫠 Esquena caigudaNomés si es veuen les dos espatlles: el cap baixa cap a elles. Si no es veuen, s'ignora sense avisar.
G7✋ Mà obertaEls quatre dits estirats.
G8✊ PunyCap dit estirat, el polze no.
G9👍 Polze amuntPolze estirat cap amunt i els altres dits tancats.
G10✌️ VictòriaÍndex i cor estirats, anular i menut tancats.
G11↕️ Assentint (sí)El cap puja i baixa dues voltes o més.
G12↔️ Negant (no)El cap va d'un costat a l'altre dues voltes o més.
ℹ️ Prioritats. Si fas dos gestos alhora, guanya el primer d'esta llista: saludar, victòria, polze, puny, mà a la cara, mà oberta, i després els moviments del cap (sí/no), l'esquena caiguda i, per últim, el cap inclinat.
⚠️ Sí i no amb el cap. Cal fer-los ben marcats i a un ritme tranquil (un parell de voltes en un segon i mig). Si no es detecten, baixa Moviment del cap a Configuració (més baix = més sensible); si salten sense voler, puja'l.
✅ Primera vegada. Els models de la cara i de les mans van inclosos a PIAR. Només PoseNet (espatlles i vista «Cos sencer») es descarrega de Google una vegada (unes poques MB) i queda guardat; si no es pot descarregar, JEmo continua sense llegir les espatlles.

Vista «Cos sencer»

PoseNet troba 17 punts del cos (cap, espatlles, colzes, canells…) i JEmo n'extrau gestos. Cal que el cap i les dos espatlles es vegen.

CodiGestCom es detecta
G1🙌 Braços amuntUn canell, o els dos, clarament per damunt del cap.
G2👋 SaludantMà alçada per damunt de l'espatlla movent-se a un costat i a l'altre.
G3🙅 Braços creuatsCada canell cap a l'altra banda del pit.
G4🤦 Mans a la caraUna mà (o les dos) damunt de la cara o del cap.
G5🤔 Cap inclinatEl cap ladeja cap a una espatlla (a partir de 15° per defecte).
G6🫠 Esquena caigudaEl cap baixa cap a les espatlles (encorbat).
ℹ️ Prioritats. Mans a la cara, braços creuats, saludar, braços amunt, esquena caiguda i, per últim, cap inclinat.
⚠️ Distància. El mòbil ha de veure de la cintura cap amunt. Massa a prop, no es veuen els braços; massa lluny, els punts es fan imprecisos. Entre 1 i 2 metres va bé. Amb la càmera frontal a un braç de distància, usa la vista «Cerca».

Cara + cos: reforç i calibratge

Si Què llig és «Cara i gestos» i està marcat Reforçar l'emoció amb el cos, el cos suma una mica a l'emoció que li encaixa (no la decideix ell sol):

GestReforça
🙌 Braços amunt · 👋 SaludantAlegria (i un poc de sorpresa)
🙅 Braços creuatsEnuig
🤦 Mans a la caraPor i sorpresa
🫠 Esquena caigudaTristesa
👍 Polze amunt · ✌️ VictòriaAlegria
✊ PunyEnuig (un poc)

Calibrar (🎯)

  1. Seu recte, amb la cara relaxada mirant la càmera.
  2. Prem 🎯 Calibrar i espera 2 segons.
  3. Es guarda la teua cara neutra (millora el model de punts) i la teua postura recta (per a detectar millor l'esquena caiguda; es guarda per separat per a cada vista).
ℹ️ Es guarda al dispositiu. Pots esborrar-lo a Configuració. Cada persona té el seu, així que torna a calibrar si canvia qui està davant.

Què s'envia i quan

Cada missatge és una línia de text acabada en salt de línia (els missatges llargs es troceen en blocs de 20 bytes, com a les altres apps):

E1emoció
:
87força %
Opció (⚙️ Configurar)Què fa
Quan enviaNomés quan canvia (recomanat): un missatge cada vegada que canvia l'emoció o el gest. Contínuament: repeteix cada 0,2–2 s encara que no canvie.
SuavitzatTemps que ha de mantindre's una lectura abans de canviar (0,6 s per defecte). Més alt = menys parpelleig, però més retard.
Confiança mínimaUna emoció nova no guanya si no arriba a este percentatge.
Cap inclinat a partir deEls graus que cal inclinar el cap per a detectar-ho.
Afegir la forçaSi el lleves, només s'envia E1, G2… (més fàcil de programar). E9 i G0 no porten força mai.
Codis dels missatgesPots posar el teu propi text per a cada emoció o gest (p. ex. «hola» per a alegria): s'enviarà tal qual.
✅ Gestos → accions teues. Amb els codis propis cada gest pot enviar el que vulgues («ences», «apaga», «salta»…) i la micro:bit només ha de comparar eixe text.
ℹ️ Es reenvia en connectar. Quan connectes la micro:bit, JEmo li torna a enviar l'estat actual.
13

Sense Internet

JEmo funciona sense connexió si ho prepares abans:

  1. Amb Internet, a la pantalla principal de PIAR prem «Descarregar per a ús sense Internet»: guarda l'app i els models de la cara i de les mans (i el del cos).
  2. O, simplement, usa JEmo una vegada amb Internet (amb la càmera encesa) perquè el model del cos quede guardat.
  3. Després, en mode avió… però no actives el mode avió si vols Bluetooth (o torna a activar-lo).
ℹ️ Res no necessita Internet per a funcionar. Ni la càmera ni els models ni el Bluetooth. Només el model del cos (vista «Cos sencer» i espatlles) es descarrega de Google la primera vegada.
14

Idees per a classe

  • Pot una màquina saber com et sents? Proveu cares exagerades i subtils. Què encerta? Què no? Hi ha emocions que no es poden «veure»?
  • Prejudicis dels models: proveu amb persones diferents (edat, tons de pell, ulleres, barba). Funciona igual de bé per a tots? Què diu això de les dades amb què s'entrenen?
  • Models comparats: la xarxa neuronal contra les regles de punts. Quina encerta més? Quina fa més errors, i en quines emocions?
  • Teatre d'emocions: un grup fa una emoció, l'altre programa què fa la micro:bit (un robot que s'alegra, que s'enfada…).
  • Semàfor de gestos: «mans amunt» = vull parlar, «braços creuats» = no entenc. Una micro:bit a la taula del professor s'il·lumina.
  • Privacitat: per què és important que la imatge no isca del mòbil? Què passaria si s'enviara a un servidor?
  • Ètica: està bé que un sistema «llija» les emocions dels alumnes en classe? Qui hauria de decidir-ho?
