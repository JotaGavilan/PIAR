    👨‍👩‍👧 Control parental (Family Link)

    El mòbil té Family Link? Llig açò

    Què pot passar

    Family Link és l'aplicació de control parental de Google. Pot fer que el navegador Chrome:

    • només òbriga llocs aprovats (i bloquege els servidors d'on les apps agafen els models d'IA);
    • limite els permisos que Chrome pot donar a una web: càmera, ubicació o dispositius propers (Bluetooth);
    • impedisca que el xiquet o la xiqueta canvie eixos permisos des del seu mòbil.

    Com saber si és això

    • El test diu que la càmera o el Bluetooth estan bloquejats «a l'instant», sense haver preguntat res.
    • L'interruptor del permís apareix en gris, o es torna a desactivar sol.
    • Falla algun servidor d'Internet encara que la Wi-Fi o les dades vagen bé.

    Qui ho ha d'arreglar

    La persona adulta responsable (pare, mare o tutor/a), des de l'app Family Link o des de familylink.google.com. El xiquet o la xiqueta no ho pot canviar sol.

    Passos per a l'adult

    Els noms dels menús poden canviar un poc segons la versió de l'app.

    1. Obri l'app Family Link i tria el perfil del menor.
    2. Entra a Controls → Restriccions de contingut → Google Chrome. Tria «Permet tots els llocs». Si es prefereix «Només permet llocs aprovats», entra a Gestiona llocs i afig els que el test diu que fallen (normalment: jotagavilan.github.io, storage.googleapis.com, tfhub.dev i teachablemachine.withgoogle.com).
    3. Comprova que no hi haja límits als permisos que les webs poden demanar (càmera, ubicació), en la configuració de Chrome del menor.
    4. En els permisos de les aplicacions del menor, deixa que Chrome use la càmera i «Dispositius propers» (en Android 11 o anterior: la ubicació).
    5. Al mòbil del menor, tanca Chrome del tot, obri-lo de nou i repeteix este test.

    Family Link filtra sobretot les pàgines que s'obrin; no sempre bloqueja els fitxers que carrega una pàgina. Per això el test comprova cada servidor un per un.

    Altres opcions

    • Si el mòbil o la tauleta són del centre educatiu (Google Workspace for Education, Chromebook), els permisos els gestiona l'administració del centre.
    • Si no es pot tocar el control parental: usa un altre dispositiu (un ordinador amb Chrome o Edge, o una tauleta sense restriccions).
